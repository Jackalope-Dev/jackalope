# Jackalope 0.1.26

Status: ready
Date: 2026-10-28

## Highlights

- Agents keep working. Routine requests from Claude Code, Kimi Code and OpenCode
  are approved automatically and listed in the task's activity. Deletes, force
  pushes, deploys, credentials, elevated commands and changes outside the project
  still ask. Turn it off for any project in its settings.
- Choose where each project's tasks work: an isolated worktree, a new branch in
  the project, directly on the current branch, or ask each time.
- Jackalope learns from your work. Preferences, corrections and checks that pass
  become lessons every agent receives. New lessons stay on probation until tasks
  use them, unused ones are archived, and each keeps a history you can review in
  Project context or with `/learnings` in the terminal.
- A redesigned terminal. `jackalope` now matches the app: a rounded card on the
  app's colours, tabs for every open conversation (Alt+1–9 or a click switches),
  a banner that says what a blocked conversation needs, `@` for agents as well as
  files, and command, shell and mention modes from a leading `/`, `!` or `@`.

## Improvements

- Claude Code keeps one session warm for each conversation, so follow-ups start
  sooner and reuse the prompt cache. Replies stream as they are written.
- Claude Code fixes problems from a project's new **Check after each edit**
  command right away, keeps working when the verification command fails before it
  finishes, and receives project lessons with every message.
- A pinned Claude model falls back to another when it is overloaded.
- Conversations and tasks switch the whole window between their views, and
  secondary actions across the app move into options menus so each page leads
  with its next step.
- New task branches are named after the request, such as
  `jackalope/fix-login-bug-909b03`.
- `jackalope merge` explains what to do instead when the work ran on a new or
  the current branch.

## Fixes

- Saved check commands containing double quotes run correctly on Windows.
- The terminal draws each frame whole, so it no longer flickers while it updates.

## Known issues

- Gemini CLI, Grok and Antigravity follow their own approval rules; automatic
  approval covers Claude Code, Kimi Code and OpenCode.
- Learning thresholds are early defaults and may archive or keep lessons sooner
  or later than you expect. Restore any archived lesson from Project context.
- Recursive Flint needs Ollama 0.40.8 or newer. Update Ollama before you start its
  23 GB download.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Signed installation and updates still need validation on each platform.

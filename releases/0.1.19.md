# Jackalope 0.1.19

Status: ready
Date: 2026-10-12

## Highlights

- Anyone can create a free account. Sign up on jackalope.dev and confirming your
  email gives you access; the waitlist is gone, and everyone who was on it already
  has an account under the same email.
- A quicker start. Project setup now takes three steps: the project, your agents
  and an optional first task. With no agent CLI installed, you can connect an API
  key or a local model right on the agents step.
- One simpler workspace. Work stays in a sidebar you can fold away, with list and
  board views. Each piece of work shows its kind: conversation, task, planned task
  or draft.
- Ship from a finished task. Create pull request commits the remaining changes
  with your commit settings, pushes the branch and opens the pull request with
  your GitHub CLI. Failing checks are listed, and the agent can draft a fix.

## Improvements

- The Agents page holds the default agent, quota handoff and account groups beside
  the agent list, with one switch for this project or all projects.
- Schedules moved under Bots, so a bot's wake-ups and recurring tasks sit together.
- The `jackalope` command can compare agents (`-p --agents claude,codex`), stream
  progress as JSON lines (`--stream-json`), print a conversation's changes
  (`jackalope diff`), and merge or open a pull request (`jackalope merge`,
  `jackalope pr`) after asking first.
- `--agent` and `--model` choose the agent and model for a new conversation.
- Settings gathers developer tools under Advanced, and status-bar counts open the
  list of the work they count.
- Review uses the full width on narrower windows.
- The restart-to-update button lines up with the other title bar controls.

## Fixes

- Returning to a terminal puts the keyboard focus back in it.
- The status bar and the work page no longer disagree about how much work needs you.

## Known issues

- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Bot memory, wake-ups and messages between bots still need validation with real
  accounts in installed builds.
- Signed installation and updates still need validation on each platform.

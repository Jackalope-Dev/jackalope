# Jackalope 0.1.22

Status: ready
Date: 2026-10-13

## Highlights

- Claude Code asks before it acts. When Claude Code needs a command or tool its
  settings do not already allow, Jackalope shows the request, with the exact
  command, and waits for your answer. Before, those requests were refused without
  asking you.
- Always allow, per project. Approve a tool, or a command such as `pnpm add`, for
  one project so Claude Code stops asking. Commands that chain, pipe or redirect
  always ask.

## Improvements

- `jackalope answer <id>` shows the question a conversation is waiting on and
  answers it by option number or text, so scripts and `-p` users can reply.
- Agents ask through Jackalope and carry on after your answer instead of ending
  their turn on a question.
- The terminal opens line by line from the bottom up. Reduced motion skips it.
- Question menus in the terminal show the whole question above the choices.
- Conversations waiting on you show in amber; red is kept for failures.
- The notification close button is smaller, and its hover stays readable.

## Fixes

- A run that ends with an action still denied now shows that it needs you and
  names what was blocked, instead of showing as ready to review.
- `jackalope -p` with `-r` or `-c` now explains how to reply instead of starting a
  new conversation with the flags as its message.
- Replies no longer end with "Commit message: None" when nothing changed.

## Known issues

- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Signed installation and updates still need validation on each platform.

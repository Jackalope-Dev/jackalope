# Jackalope 0.1.31

Status: ready
Date: 2026-10-31

## Highlights

- A denser workspace built around your projects. The sidebar lists each project
  with the work that needs you first, then running and recent work with its
  agent and live status. Search moves into the title bar and the branch moves to
  the status bar. On Windows 11 and macOS the window is frosted; turn it off under
  Settings → Appearance → Frosted window.
- Plan with me before code changes. Choose **Plan with me** in the composer,
  `/plan` in the terminal or `jackalope plan`. The planner checks facts in your
  code instead of asking you, drafts one plan with tasks and acceptance criteria,
  and runs an approved revision as one agent, planned subtasks or a swarm, with
  an independent review against every criterion.
- Agents keep working. Routine requests from Claude Code, Kimi Code and OpenCode
  are approved automatically and listed in the task's activity, while deletes,
  force pushes, deploys, credentials and changes outside the project still ask.
  Conversations now keep going until you pause or stop them, or a reply needs
  you, including after Jackalope restarts.
- Agents can use your apps and signed-in browser. Grant one window, one app or
  the full desktop; agents act on buttons and fields by name, and each website
  in your browser asks once. Bots can also get their own Linux computer in Docker
  or a paired cloud machine.
- Agents show their work. Expected outcomes say how strong the evidence is,
  Jackalope checks cited files, test output and screenshots, and **Challenge this
  change** asks other agents to break a result. Finished work arrives with before
  and after screenshots in Review.
- Jackalope learns from your work. Preferences, corrections and passing checks
  become lessons every agent receives, kept few and distinct, with lessons agents
  keep missing supplied first. **Make it a check** turns one into a lint, type,
  test or CI check.
- Choose where each project's tasks work: an isolated worktree, a new branch, the
  current branch, or ask each time.

## Improvements

- Agent questions get room to answer: number keys pick an option, Enter sends, and
  a stopped task continues with the answer you choose.
- The app and the `jackalope` terminal stay in step, including half-typed
  messages. The terminal is redesigned to match the app, with tabs for open
  conversations and `/merge`, `/pr`, `/status`, `/unqueue` and `/sharpen`.
- **Since you left** names what needs you after you have been away, and long work
  keeps a **Decision log** of what the agent chose and why.
- Compare attempts with a judge, and **Keep and combine** brings the best parts of
  the others into the one you keep.
- Right-click a project in the sidebar for its actions, including **Set icon…**.
- **Create pull request** drafts its title and description from the branch's
  changes alone, never from your request or the conversation.
- Hover a message to see when it was sent. **Review changes** and **Review and
  merge** only appear once work changed files.
- Claude Code keeps one session warm per conversation, streams replies and falls
  back to another model when a pinned one is overloaded.
- Agent browsers can stay signed in per project or bot, and desktop control works
  on KDE Plasma and GNOME under Wayland.
- Recursive Flint · 40B is available as a local agent through Ollama.
- The usage pop-out shows each allowance on one compact row with when it resets.
- Controls are more compact with a mouse or trackpad and keep larger targets on
  touch screens. New installs follow your system's light or dark setting.

## Fixes

- A reply sent after reopening Jackalope no longer sits on "Queued".
- The Auto theme no longer shows light on a dark system until you change colors.
- In the terminal, a typed reply can no longer deny a permission request by
  accident, and frames no longer flicker.
- Saved check commands containing double quotes run correctly on Windows.
- When Ollama is too old for a model, setup says to update Ollama.
- Long work titles no longer widen the Work list.

## Known issues

- Conversations saved as paused by earlier versions stay paused until you send a
  message in them or press Resume.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal; other Wayland desktops are not supported yet.
- Bot computers need Docker for a local sandbox. Jackalope-hosted computers are
  not available yet.
- Recursive Flint needs Ollama 0.40.8 or newer.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Frosted glass on macOS has not been checked on a device yet.
- Signed installation and updates still need validation on each platform.

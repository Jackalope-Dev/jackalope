# Jackalope 0.1.37

Status: ready
Date: 2026-11-17

## Highlights

- **A cleaner, guided Jackalope.** The sidebar starts with an Inbox of what needs
  you, and the board has real lanes: Needs you, Working, In review, Drafts and
  Finished, with every row saying why it needs you. Settings are regrouped and
  stay inside Settings, each project has its own settings with a How hands-on?
  preset, and setup screens guide you step by step. Back and Forward buttons
  beside the app name (Alt+Left and Alt+Right, Cmd+[ and Cmd+] on Mac, or a
  mouse's side buttons) step through the pages and projects you visited.
- **Follow pull requests from the work list.** Create a pull request with an
  AI-written title and description, or commit or merge locally in one step. After
  a pull request opens, Jackalope keeps watching it, shows whether it is waiting
  on checks or review, needs a fix or is ready to merge, and notifies you when
  that changes. One click drafts the fix for failed checks, review comments or a
  conflict; pushing and merging each ask first.
- **Get a second opinion without leaving the task.** **Agent review** on the
  Review tab has an agent from another model family read the changes and return
  findings with severity, file, line and a fix plan. **Make these changes** hands
  the ones you keep back to the same task.
- **Agents decide the routine, you decide what matters.** Turn on Autonomy in
  Project settings, and on approved plans another agent answers routine
  questions and accepts small changes inside the plan's scope, showing who
  decided, why and how sure, with Override. Commit `.jackalope/autonomy.json` to
  choose which paths and change sizes may merge without waiting for you.
  Sign-ins, payment, secrets, publishing, deletions, protected paths and changes
  of direction always come to you.
- **Swarm (Beta)** builds large projects in rounds. Approve a plan and an
  orchestrator splits it into tasks for several agents, reviews each round, then
  finishes or proposes the next one; choose **Ask me first** to approve each
  round. The Swarm page opens on a live map of tasks with shared files and
  conflicts between them. Set it up from Settings in one click by connecting
  Cloudflare, and spread rounds across this device and your computers.
- **Agents on a computer (Beta)** run a project's agents on another machine.
  Pair one with a ready-made `docker run` command or add an Agent37 computer with
  your own key. Jackalope sends the workspace, runs the agent there with its own
  desktop, browser and checks, streams the output back and applies the result
  for the usual review and merge.
- **Cloud resources (Beta)** create R2 storage, a D1 database, KV, Queues,
  Hyperdrive and Turnstile in your own Cloudflare account from Project settings,
  and give you the wrangler bindings. Retrying never makes duplicates.
- **Pick up where you left off.** Claude Code and Codex conversations you had in
  a terminal or another app appear under their project; open one to read it or
  continue it in the same checkout. Nothing is uploaded, and Settings → Privacy
  turns it off. Work that was running when Jackalope closed has a Resume button.

## Improvements

- Useful settings now start on: finished work is checked with your project's
  check command, your computer stays awake while agents work, a learning step
  reflects on finished work with your default agent (a few short calls a day),
  stopped terminal output is restored and updates download in the background.
  Each can be turned off.
- Setup asks for less: agents install from onboarding with one click, detected
  API keys are offered automatically, and agents sign in during project setup.
  Add agent lists known ACP agents such as Cursor, GitHub Copilot CLI, Goose and
  Qwen Code, and fills in the ones installed.
- Fewer permission questions for routine commands, and **Always allow** works for
  chained commands. Installing software beyond the project now asks first.
- Every project has a **Secrets** section for keys agents can use, and secret
  values are removed from an attempt's saved record. Project instructions, cloud
  resources and pasted images reach every agent automatically.
- Failed attempts say what kind of failure it was, such as sign-in, quota or an
  unavailable model, with a next step.
- Pairing a phone takes one step with a QR code, a short fallback code and a
  guided Tailscale setup. Paired phones and machines get recognizable names.
- Share a project's bots as one file and import a reviewed one; bots have a new
  gallery, schedules use one When picker, and bots can work across projects.
- New work starts from the Work composer. Replies can be read aloud, and a
  conversation can be copied as Markdown.
- The terminal shows each run as a card with its stages, checks and changed
  files, has a board of open conversations, and docks agent questions where you
  type.
- Jackalope Violet is the default theme, the frosted window is a step more
  opaque, and the sidebar shows the logo of the agent that worked on each task.
- Usage views show tokens only, since list-price cost estimates didn't match
  subscription billing.
- On macOS the `jackalope` command is added to your PATH automatically.

## Fixes

- Primary buttons, including Connect account, no longer show a faint label in
  installed builds.
- Project instructions reach every agent again, including work started from the
  Work composer.
- New project paths and saving a project's to-do list work reliably on Windows.
- A continuation whose agent session is gone starts once as a new conversation
  instead of pretending to resume.
- A used-up Claude window is reported as out of quota, and each model is sent
  only an effort level it accepts.
- Remote access no longer refuses an unopened project with "Choose a valid local
  branch".
- The window stays responsive while commands wait for another task, and
  switching tabs no longer flashes the start screen.
- A fetched site icon shows in the icon dialog straight away.
- Long titles and names fit on narrow windows.

## Known issues

- Swarm, agents on a computer, Cloud resources and Autonomy are in beta. Swarm
  and Cloud resources use your own Cloudflare account; computers use Docker or
  your own Agent37 key. Jackalope doesn't host computers yet.
- If you never set Check results automatically, it is now on; turn it off in
  Project settings if you don't want checks to run.
- Back and Forward return to the page and project, not to the task that was open
  in Work.
- The phone companion is not in the App Store or Play Store yet. Installed phone
  builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

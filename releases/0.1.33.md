# Jackalope 0.1.33

Status: ready
Date: 2026-11-06

## Highlights

- **Swarm (Beta)** can build a large project in rounds. Approve a plan and an
  orchestrator splits it into tasks for several agents. A read-only orchestrator
  reviews each round, then either finishes or proposes the next one. Choose
  **Ask me first** to approve, edit or stop each proposed round. Large swarms
  split review across area orchestrators. Rounds are also available from the
  terminal.
- Set up Swarm from Settings in one click. Connect Cloudflare, and Jackalope
  deploys its Swarm Worker to your account, connects Artifacts and finds your
  account from a pasted API token. Disconnecting offers to delete the Worker.
- **Agents on a computer (Beta)** run a project's agents on another machine
  instead of yours. Pair a computer with the ready-made `docker run` command, or
  add an Agent37 computer with your own Agent37 key. Jackalope uploads the task's
  workspace, runs the agent there with its own desktop and browser, streams the
  output back and applies the result for the usual checks, review and merge.
  Choose where a project's agents run, and save their sign-ins, in Project
  settings.
- New work starts from the Work composer, and bots are grouped by project. One
  bot can work across several projects.

## Improvements

- Setup asks for less. Agents can be installed from onboarding with one click.
  Detected API keys are offered automatically, and agents sign in during
  project setup. The setup screen checks again when you come back to it.
- If Artifacts finds a repository with no commits, it offers to make the first
  one, and Artifacts can be connected from Project settings.
- Pairing a phone takes one step, and pairing codes appear as you'd type them.
  Paired machines are named after their bot or project.
- Jackalope Violet is the default theme in the app, the terminal and the website.
- The terminal shows each run as a card with its stages, checks and changed files,
  and has a board of open conversations. Menu rows, run cards and tips are
  clickable.
- Routing picks an agent faster and falls back to your local rules if it takes
  more than a few seconds.
- On macOS the `jackalope` command is added to your PATH automatically.

## Fixes

- New project paths work on Windows.
- Switching tabs no longer flashes the start screen before a conversation
  appears.
- Merging from a terminal conversation pauses the agent first, and the
  conversation resumes if the merge doesn't go ahead.
- The status bar no longer starts a new count of changes while the previous one
  is still running.

## Known issues

- Swarm and agents on a computer are in beta. Swarm uses your own Cloudflare
  account. Agents on a computer use Docker or your own Agent37 key. Jackalope
  doesn't host computers yet.
- The phone companion is not in the App Store or Play Store yet. Installed
  phone builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

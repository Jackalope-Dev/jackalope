# Jackalope 0.1.7

Status: ready
Date: 2026-09-25

## Highlights

- The macOS disk image opens to the branded Jackalope installer window.

## Improvements

- The drag-to-Applications layout in the macOS installer shows the app and
  Applications folder side by side.

## Fixes

- Released macOS downloads no longer open as a plain, unstyled Finder window.

## Known issues

- This is a prerelease for testing. Signed installation and updates still need
  validation on each platform.
- Some Changes-page errors after committing may still require reloading.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

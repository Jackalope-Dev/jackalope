# Jackalope 0.1.32

Status: ready
Date: 2026-11-03

## Highlights

- Get a second opinion without leaving the task. **Agent review** on the Review
  tab has an agent from another model family read the changes and return a short
  list of findings with severity, file, line and a fix plan. **Make these
  changes** hands the ones you keep back to the same task.
- Let verified work merge on its own. Commit `.jackalope/autonomy.json` to choose
  which paths and change sizes Jackalope may merge without waiting for you.
  Protected paths, the policy itself and CI configuration always wait for you.
  Merges can push to Artifacts and run your deploy, pausing if a deploy fails.
- The Swarm page opens on a live map of every task working toward the target
  branch, with shared files and conflicts shown between the agents changing them.
- Finish work your way: create a pull request with an AI-written title and
  description, or commit or merge work in your project checkout locally in one
  step.
- Pairing a phone is easier. Remote access leads with a QR code to scan, keeps a
  short ten-character code one tap away if you can't scan, and walks you through
  private HTTPS with Tailscale step by step, linking straight to any setting
  Tailscale needs turned on. Advanced connection settings stay folded away. The
  phone companion itself is still in testing.

## Improvements

- Fewer permission questions: heredoc commit messages, saving a command's output
  in a variable, reading `process.env` and pushing your working branch no longer
  ask, and **Always allow** works for chained commands. Installing software beyond
  the project, such as Homebrew packages or global npm tools, now asks first.
- Reviewers see the task's recorded checks, decisions and screenshots, so they
  don't flag proven work as unchecked.
- Usage views show tokens only. Cost estimates came from each agent's list prices
  and didn't match subscription billing, so they are hidden.
- The frosted window lets your desktop show through on macOS, and the macOS window
  buttons line up with the title bar and sidebar.
- In the terminal, agent questions dock where you type, tabs close with × or
  `/close` while their work keeps running, and Ctrl+T or `/tabs` hides the top bar.
- Phones pair under your name, such as Alex's iPhone, instead of a generic name.
- The Terminal button opens your system terminal directly.

## Fixes

- Remote access no longer refuses a project that hasn't been opened yet with
  "Choose a valid local branch".
- Reviewing uncommitted changes from Changes no longer runs the project's saved
  check in a different folder.
- The window stays responsive while commands wait for another task to finish.
- On Windows 11 the window is now transparent, which the frosted effect needs.
- Challenge rerun output survives reloads.

## Known issues

- The phone companion is not in the App Store or Play Store yet. Installed
  phone builds pair only over HTTPS, such as a Tailscale address.
- Frosted glass has not been checked on every macOS and Windows device yet.
- Conversations saved as paused by earlier versions stay paused until you send
  a message in them or press Resume.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal; other Wayland desktops are not supported yet.
- Bot computers need Docker for a local sandbox. Jackalope-hosted computers are
  not available yet.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Signed installation and updates still need validation on each platform.

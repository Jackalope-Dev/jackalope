# Jackalope 0.1.27

Status: ready
Date: 2026-10-29

## Highlights

- Plan with me before code changes. Choose **Plan with me** in the composer,
  `/plan` in the terminal or `jackalope plan`. The planner reads your code
  read-only, asks only what it cannot find (recommended answer first), and drafts
  one plan with assumptions, tasks and acceptance criteria. Approve an exact
  revision to run it as one agent, planned subtasks or a swarm; an independent
  review checks the result against every criterion. Departures from the plan
  pause dependent work until you accept, redo or re-plan. **Write the plan
  myself** turns your own tasks into the same plan.
- Agents can use your apps and signed-in browser. Grant one window, every window
  of one app, or the full desktop; full desktop asks every task, while window and
  app grants can be remembered per project. Agents act on buttons and fields by
  name through accessibility, so they usually leave your mouse alone, and each
  action answers in milliseconds on Windows. In your own browser each new website
  asks once.
- Bots get their own computer: a Linux desktop with a browser in Docker on your
  machine, or a cloud machine you pair in Settings → Computers. Start, stop, watch
  or take over it from the bot's settings. Local sandboxes start when needed and
  stop after 10 idle minutes.
- Before and after screenshots in Review. Finished work arrives with captures of
  the pages it changed, compared with a slider or side by side.

## Improvements

- Agent browsers stay signed in: each project and bot can keep its own browser
  profile. Agents ask before each site and pause for you to sign in yourself;
  passwords never reach the agent. Manage profiles in Project settings, the bot
  editor or `/browser`.
- Desktop control works on KDE Plasma and GNOME under Wayland through your
  desktop's own sharing prompt.
- Learned lessons stay few and distinct: near-duplicates strengthen the saved
  lesson, projects keep at most 20, and only the 12 most-used are exported.
- Lessons agents keep missing are marked **Often missed** and supplied first;
  lessons that name files or scripts that no longer exist are archived or flagged
  **Out of date**.
- Optionally sync learned lessons between your desktops, let your default agent
  reflect on finished work, or mirror active lessons into AGENTS.md and a Claude
  Code skill. All are off by default.
- Plans run in projects without a saved check, verified by the plan's own test
  commands or by review alone.

## Known issues

- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal; other Wayland desktops are not supported yet.
- Bot computers need Docker for a local sandbox. Jackalope-hosted computers are
  not available yet.
- Recursive Flint needs Ollama 0.40.8 or newer.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.25

Status: ready
Date: 2026-10-27

## Highlights

- Recursive Flint for local agents. Agents → Try a local agent now offers
  Recursive Flint · 40B, a fast open coding model for computers with 48 GB of
  memory or more. It downloads through Ollama like the other local models and
  must pass the same local check before you connect it.

## Fixes

- When your Ollama is too old for a model, setup now says to update Ollama
  instead of pointing at your connection or free disk space.

## Known issues

- Recursive Flint needs Ollama 0.40.8 or newer. Update Ollama before you start
  its 23 GB download.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Signed installation and updates still need validation on each platform.

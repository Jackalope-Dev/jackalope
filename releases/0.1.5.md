# Jackalope 0.1.5

Status: ready
Date: 2026-09-24

## Highlights

- One workspace for conversations, tasks and plans, with a shared Work page, a bottom
  status bar and Focus, Build and Oversee modes.
- The `jackalope` terminal command starts and rejoins routed conversations from a Git
  repository. Open it from the status bar or Cmd/Ctrl+J, then continue the same
  conversation in your own terminal.
- Changes can discard work you no longer want, and when a commit hook rejects a
  commit it shows the hook's output and can fix the problem with an agent in place.
- Run Gemini CLI tasks, and connect DeepSeek and other supported API providers without
  installing a separate agent.

## Improvements

- Signed and notarized macOS builds with a Jackalope-branded installer window and
  in-app updates.
- Follow active work as it happens, with file activity and live check output in tasks
  and chats.
- Project decision preferences combine local rules, agent reasoning and optional
  Jev-assisted routing, with a chosen fallback.
- A curated MCP marketplace and macOS window, menu and Dock integration.

## Fixes

- Account connection errors show the specific reason, such as a device limit.
- Launching Jackalope while it is already running opens the existing window.
- Feedback can be sent from signed builds, and a failed update check says why.

## Known issues

- In some cases the Changes page can go blank after a commit.
- Running tasks requires approved Jackalope account access and an installed, signed-in
  agent CLI or a connected API provider.

# Jackalope 0.1.16

Status: ready
Date: 2026-10-05

## Highlights

- Bots can now work on their own. Wake a bot on a schedule, when the project
  changes or when a connected app returns new data, and follow each wake-up in
  its conversation on the Bots page.
- Bots work together. A bot can find your other bots, ask one for help and get
  the reply back in the same conversation, with every message labelled.
- Bots bring you what needs you: decisions with options, questions, suggested
  next steps and the sources they used appear as cards you can answer from the
  conversation or the bot's Needs you section. Bots can also suggest new bots
  for you to review.

## Improvements

- The Bots item in the sidebar counts cards waiting on you, and with
  notifications on, Jackalope tells you when a bot needs you while it is in the
  background.
- Pause all wake-ups from the Bots page; the status bar shows when they are
  paused and lets you resume them in one click.
- Settings categories and their content scroll separately on wide windows.
- In-app help is up to date with the current workspace, with new guides for
  getting started, workspace modes and bots.

## Fixes

- The companion's speech bubble button stays readable on hover and takes less
  space.

## Known issues

- Bot wake-ups, connection watching and messages between bots still need
  validation with real accounts in installed builds.
- Signed installation and updates still need validation on each platform.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

# Jackalope 0.1.21

Status: ready
Date: 2026-10-13

## Highlights

- Anyone can create a free account. Sign up on jackalope.dev and confirming your
  email gives you access; the waitlist is gone, and everyone who was on it already
  has an account under the same email.
- A quicker start and one simpler workspace. Project setup takes three steps: the
  project, your agents and an optional first task. With no agent CLI installed, you
  can connect an API key or a local model during setup. Work stays in a sidebar
  you can fold away, with list and board views.
- Bots that work on their own. Wake a bot on a schedule, when the project changes
  or when a connected app returns new data. Bots can ask each other for help, keep
  short notes for later conversations and bring you decisions and questions as
  cards you answer from the conversation.
- Ship from a finished task. Create pull request commits the remaining changes,
  pushes the branch and opens the pull request with your GitHub CLI. Failing checks
  are listed, and the agent can draft a fix.
- A much more capable `jackalope` command. Follow an agent's newest steps, review
  changed files and diffs in a panel beside the conversation, compare agents
  (`-p --agents claude,codex`), choose the agent and model, stream progress as JSON
  lines and merge or open a pull request after asking first.

## Improvements

- A cleaner, more consistent look: pages, tabs and controls share one style, with
  dialogs and pages that ease into place. Reduced motion keeps everything still.
- The Agents page holds the default agent, quota handoff and account groups beside
  the agent list, with one switch for this project or all projects.
- Schedules moved under Bots, so a bot's wake-ups and recurring tasks sit together.
- Agents start sooner, and receive shorter instructions focused on your workspace,
  permissions and review.
- Conversation text can be selected and copied, and the branch menu can copy the
  branch and workspace path.
- Settings gathers developer tools under Advanced, and status-bar counts open the
  list of the work they count.
- In-app help covers getting started, workspace modes and bots.

## Fixes

- Long model lists scroll inside the agent picker instead of being cut off.
- Long-running tasks show elapsed time in hours and days.
- Status badges keep their contrast in dark themes.
- Returning to a terminal puts the keyboard focus back in it.
- The status bar and the work page agree about how much work needs you.
- Updated bundled dependencies past newly reported security advisories, including
  three denial-of-service advisories in a networking library.

## Known issues

- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Bot memory, wake-ups and messages between bots still need validation with real
  accounts in installed builds.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.1

Status: ready
Date: 2026-09-23

## Highlights

- One workspace for conversations, tasks and plans, with a shared Work page, a bottom
  status bar and Focus, Build and Oversee modes.
- Follow active work as it happens, with file activity and live check output in tasks
  and chats, then review large changes promptly beside their checks.
- Run Gemini CLI tasks, and connect DeepSeek and other supported API providers without
  installing a separate agent; Jackalope can prepare a private runner.
- An early `jackalope` terminal command starts and rejoins routed conversations from a
  Git repository and can run Jackalope in the background.

## Improvements

- Project decision preferences combine local rules, agent reasoning and optional
  Jev-assisted routing, with a chosen fallback.
- Task assessments, reviewed plans and a combined result for parallel work keep related
  changes under one parent task.
- Codex speed controls, less repeated startup work and concise successful test output
  make tasks faster to run and easier to read.
- A curated MCP marketplace, field selection for large tool results and OpenCode
  permission requests inside the task question flow.
- macOS window, menu and Dock integration, task terminals, separate windows and
  reversible chat topics.

## Fixes

- Account connection errors show the specific reason, such as a device limit, and the
  connection check recovers on its own instead of stopping after one failure.
- Launching Jackalope while it is already running opens the existing window.

## Known issues

- This is a prerelease for testing. Signed installation and updates are being
  validated on each platform.
- Agent questions raised from the terminal command are answered in the app.
- Running tasks requires approved Jackalope account access and an installed, signed-in
  agent CLI or a connected API provider.

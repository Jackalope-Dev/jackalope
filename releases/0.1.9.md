# Jackalope 0.1.9

Status: ready
Date: 2026-09-29

## Highlights

- Compare agents: send one request to up to four agents at once, see status,
  time, checks, changed lines and tokens side by side, and keep the best result.
- Tabs keep recently opened tasks and chats close at hand. Switch with Ctrl+1
  to 9 or Ctrl+Tab.
- Attach screenshots and files to requests by pasting, dropping or picking them.

## Improvements

- Work rows show how long an agent has been running, how many lines changed and
  a dot for results you have not opened yet.
- Changes shows recent commits across your local branches.
- Command search finds project files to open in your editor or attach to work.
- Press ? to see keyboard shortcuts.
- Usage & quota shows when each Ask Jackalope question happened and which
  project was open, with project, account and period filters.
- Setup covers more agents, and setup commands are easier to read and copy.
- The `jackalope` terminal command can create a repository with `--init`.
- Jackalope starts faster by loading setup and dialogs only when needed.
- Polished layout, spacing and colors across the app.

## Fixes

- Archived Ask Jackalope conversations stay in Usage, and a helper file that
  cannot be read is reported instead of silently skipped.

## Known issues

- This is a prerelease for testing. Signed installation and updates still need
  validation on each platform.
- Ask Jackalope turns saved before this version have no date and appear under
  All time.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

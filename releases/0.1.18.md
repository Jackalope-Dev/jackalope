# Jackalope 0.1.18

Status: ready
Date: 2026-10-08

## Highlights

- See what agents are doing from the terminal. While work runs, the `jackalope`
  command lists the agent's newest steps under the conversation, and the status
  line says when a run has reported nothing new for a while.
- Review changes without leaving the terminal. A changes panel opens beside the
  conversation with each changed file and its diff. Ctrl+O shows or hides it, and
  `/review` opens the same changes in the app.

## Improvements

- Questions from an agent stay pinned above the input, and `/answer` reopens
  their choices.
- `/theme` sets a project's colour, such as purple or green, in every terminal
  and in the app.
- Projects first used from a terminal appear in an open app right away.
- `jackalope -p` prints the agent's steps as they happen.
- Conversation text can be selected and copied in the app, with copy buttons on
  messages and replies, and the branch menu can copy the branch and workspace path.
- The terminal's working indicator is calmer and smoother.

## Fixes

- The selected tab in a conversation no longer flashes a different colour while
  the selection slides between tabs.

## Known issues

- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Bot memory, wake-ups and messages between bots still need validation with real
  accounts in installed builds.
- Signed installation and updates still need validation on each platform.

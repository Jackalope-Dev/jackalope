# Jackalope 0.1.39

Status: ready
Date: 2026-11-22

## Highlights

- **Inbox, Library and a sidebar you can arrange.** Inbox gathers what needs you
  across projects: questions, failed checks, reviews, new results and alerts such as
  a low allowance. Library collects the screenshots and files your work made. Pin
  favorites, pin work to the top of a project and group work into folders.
- **Talk instead of typing.** Every composer has a mic button that turns speech
  into text on your computer. Pick a Whisper model the first time; it downloads
  once, and recordings are never saved.
- **Keep working while Jackalope uses a window.** Desktop control carries on in the
  background while you use other apps. Only clicking or typing in the granted
  window pauses it, and a Resume button on the window's badge picks it back up.
- **Your skills on every computer.** The new Skills page in Agents lists your
  Claude Code, Codex and shared agent skills. The ones you choose sync through
  your account without being committed. Skill sync is off until you turn it on.
- **Pick up quota-stopped work where it left off.** Retrying a task that a provider
  quota stopped now continues from its changes instead of starting over, with an
  optional focus line for the next agent.

## Improvements

- Switch or create branches from the branch menu in the status bar.
- Checking a web page, a connection or an attached window runs right in your
  project folder, with no worktree, setup or checks. General gives you a place for
  work that doesn't belong to any project.
- Project context offers your Cursor, Windsurf, Cline and GitHub Copilot rule files
  as lessons you can turn on. Each arrives paused and keeps its file's scope.
- The limit on agents running at once on this computer is now Automatic by default
  and follows its CPUs and memory. A number you choose is kept.
- Projects that merge automatically now run the saved check on the combined result
  before merging, so work that passes alone but breaks once combined is held back.
- On macOS and Linux, a new task worktree reuses the project's installed
  `node_modules` copy-on-write before the setup command runs, when the dependency
  files match.
- OpenCode tasks shorten passing Jest, Vitest, Playwright, Cargo, Go and TypeScript
  output and keep the full output recoverable. Failing runs stay whole.
- Oh My Pi is listed among the known ACP agents in Add agent.
- The box for continuing a conversation from outside Jackalope is now a rounded
  card that floats over the transcript.
- The Work page always shows the full composer.

## Fixes

- A provider refusing a request is reported as a refusal and no longer switches
  accounts as if the quota had run out.
- Theme picker buttons stay on one line and the palette handle no longer overflows.
- Work list rows and the filter summary have even spacing on hover.

## Known issues

- Inbox, Library, voice to text, the branch menu, Skill Sync, background desktop
  control, the combined check before automatic merges and the Automatic agent limit
  have not yet been accepted in an installed app.
- Background desktop control works on Windows and macOS. On Linux X11, any input
  still pauses it.
- Copy-on-write reuse of `node_modules` does not apply on Windows, which installs
  in full.
- Synced skill text is not end-to-end encrypted.
- The phone companion is not in the App Store or Play Store yet. Installed phone
  builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.38

Status: ready
Date: 2026-11-19

## Highlights

- **See what's holding up an update.** When tasks keep an update from installing,
  Restart to update now lists them by name, with why each one is waiting and a way
  to open it, instead of failing quietly.
- **Mark interrupted work stopped.** A task cut off when Jackalope closed can now be
  marked stopped without running it again, from the update list or beside Resume
  on the task. Nothing is lost, and you can still continue or retry it later.

## Improvements

- The Restart to update button in the title bar is smaller and sits neatly inside
  the title bar controls.

## Fixes

- An interrupted task no longer blocks updates for good. Before, the only way to
  clear one was to resume it, which kept it running.
- Cleaning up finished task workspaces no longer copies large untracked build
  folders into Git, which could use gigabytes of disk and memory.

## Known issues

- Marking interrupted work stopped and the new update list have not yet been
  accepted in an installed app.
- Back and Forward return to the page and project, not to the task that was open
  in Work.
- Followed pull requests, the ACP agent list, bot sharing and reading replies
  aloud have not yet been accepted in an installed app.
- The phone companion is not in the App Store or Play Store yet. Installed phone
  builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

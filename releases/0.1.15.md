# Jackalope 0.1.15

Status: ready
Date: 2026-10-02

## Highlights

- A new welcome screen introduces the beta, the main ways to work and how to
  tell us what you think.
- Send feedback from the bottom bar at any time: bugs, ideas or anything
  confusing.
- Updates can download in the background. When one is ready, choose Restart to
  update in the title bar. Turn this on in Settings → App updates.

## Improvements

- Jackalope's update message now offers to install right away.

## Known issues

- Signed installation and updates still need validation on each platform.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

# Jackalope 0.1.40

Status: ready
Date: 2026-11-24

## Improvements

- Updates has its own page in Settings, under Help.
- Microsoft Store builds can send feedback from the app.
- Earlier replies in live transcripts and in conversations continued from outside
  Jackalope format as they scroll into view, with no need to click "Format earlier
  response" on each one.
- What's new shows formatting such as bold text and code.

## Fixes

- On macOS, dragging the agent onto a window it is already controlling now finds
  that window instead of reporting that nothing is there.

## Known issues

- Inbox, Library, voice to text, the branch menu, Skill Sync, background desktop
  control, the combined check before automatic merges, the Automatic agent limit
  and the macOS drag fix have not yet been accepted in an installed app.
- Background desktop control works on Windows and macOS. On Linux X11, any input
  still pauses it.
- Copy-on-write reuse of `node_modules` does not apply on Windows, which installs
  in full.
- Synced skill text is not end-to-end encrypted.
- The phone companion is not in the App Store or Play Store yet. Installed phone
  builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.6

Status: ready
Date: 2026-09-24

## Highlights

- Each project keeps its own enabled agents, default agent and account choices,
  so work and personal projects can use separate preferences.
- Push a newly created commit directly from Changes.

## Improvements

- macOS permission setup links directly to missing permissions in System Settings
  and offers a restart once running work and terminals have stopped.
- Chat makes Review changes more prominent when work is ready to review.

## Fixes

- The terminal command follows saved project colors, updates them while open and
  uses closer matches on terminals limited to 256 colors.
- Opening a task that belongs to a chat takes you back to that chat, including
  when opening it from a notification.
- App-wide rendering errors show details and a reload action instead of leaving
  the window blank.

## Known issues

- This is a prerelease for testing. Signed installation and updates still need
  validation on each platform.
- Some Changes-page errors after committing may still require reloading.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

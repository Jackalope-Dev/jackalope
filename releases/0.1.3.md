# Jackalope 0.1.3

Status: ready
Date: 2026-09-23

## Highlights

- The `jackalope` terminal command can answer agent questions, choose an agent and
  edit your message before sending.
- Changes can discard work you no longer want, and the header and status bar show
  the current branch and how many files have changed.
- When a commit hook rejects a commit, Changes explains what happened, shows the
  hook's output and can fix the problem with an agent in the same checkout while
  you watch.

## Improvements

- The macOS installer opens on a Jackalope-branded window that shows where to drag
  the app.
- Setup errors for agents show a clear notice with the next step in the helper and
  on Changes.

## Fixes

- Feedback can be sent from signed builds.
- An update check that fails now says why, instead of reporting a connection
  problem.
- Ask Jackalope tries another installed agent when the first cannot answer.

## Known issues

- This is a prerelease for testing. Signed installation and updates are being
  validated on each platform.
- In some cases the Changes page can go blank after a commit.
- Running tasks requires approved Jackalope account access and an installed, signed-in
  agent CLI or a connected API provider.

# Jackalope 0.1.30

Status: ready
Date: 2026-10-31

## Highlights

- Conversations keep going. A conversation now runs until you pause or stop it,
  or until a reply needs you, instead of pausing every time Jackalope restarts.
  Sending a message in an idle conversation picks it back up, and leaving
  Review lets queued messages run again.
- Right-click a project in the sidebar for its actions: start new work, open
  its pages, copy its path, remove it, or **Set icon…** to give it one of
  thirty icons in place of its initial.
- Pull requests describe the code. **Create pull request** drafts its title and
  description from the branch's changes alone, never from your request or the
  conversation, and you can still edit both before anything is published.

## Improvements

- Hover a message or reply to see when it was sent.
- **Review changes** only appears once the work changed files, so an answer or
  report has no review button.
- The usage pop-out shows each allowance on one row with what's left and when
  it resets, so every account fits without scrolling.
- With no project selected, new work asks you to choose one of your projects
  instead of starting new project setup.
- The browser's own right-click menu no longer appears outside text fields.
- Status bar hover highlights, the branch chip, the More button and the
  notification badge line up cleanly, and conversation header buttons share
  one size.

## Fixes

- A reply sent after reopening Jackalope no longer sits on "Queued" until you
  resume the conversation.
- The Auto theme no longer shows light on a dark system and then switches to
  dark when you change colors, which also kept the frosted window too light.

## Known issues

- Conversations saved as paused by earlier versions stay paused until you send
  a message in them or press Resume.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal; other Wayland desktops are not supported yet.
- Bot computers need Docker for a local sandbox. Jackalope-hosted computers are
  not available yet.
- Recursive Flint needs Ollama 0.40.8 or newer.
- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Frosted glass on macOS has not been checked on a device yet.
- Signed installation and updates still need validation on each platform.

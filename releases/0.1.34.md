# Jackalope 0.1.34

Status: ready
Date: 2026-11-07

## Highlights

- **Agents decide the routine, you decide what matters.** Turn on Autonomy in
  Project settings, and on approved plans another agent answers routine
  questions, approves swarm rounds whose checks passed and accepts small changes
  inside the plan's scope. Each decision shows who decided, why and how sure,
  with Override. Sign-ins, payment, secrets, publishing, deletions and changes of
  direction always come to you, as a **Needs you** card with the steps to take.
- **Cloud resources (Beta)** create R2 storage, a D1 database, KV, Queues,
  Hyperdrive and Turnstile in your own Cloudflare account from Project settings.
  Pick what you need, watch each step run, and copy the wrangler bindings.
  Retrying never makes duplicates, and a missing permission is named exactly.
- **Swarms spread across your computers (Beta).** A swarm round places its tasks
  on this device, the project's computer and any computers you add, by what each
  task needs and how busy each machine is. Choose where swarms run in Project
  settings, and see each task's machine and each machine's load on the swarm
  board.
- **Agents on a computer keep their tools there.** On computers with the new
  image, checks, project context, the browser and screenshots run on the
  computer itself, on every kind of computer, while approvals stay on this
  device. Workspaces travel as Git bundles, so retries send only what changed,
  and large results arrive whole.

## Improvements

- The sidebar, task lists and phone companion show the logo of the agent that
  worked on each task most recently. Bots keep their characters.
- Every project has a **Secrets** section for keys such as service API keys,
  available to agents on this device, on computers or both.
- Agents on a computer can use the project's on-demand connections, including
  ones that run as programs such as npx and uvx servers, which start on the
  computer in the workspace the agent edits.
- Agents get the project's context automatically: cloud resources and their
  bindings, project instructions and pasted images reach every agent, in a
  worktree or on a computer, with nothing to commit or paste.
- A computer reports how many agents it has room for, so swarms put more work
  on larger added computers.
- Repository search by agents on a computer ranks files by the names they
  declare, like searches on this device.
- A new repository without commits gets its first commit automatically when
  work starts.
- The frosted window is a step more opaque, so busy windows behind it stay
  quiet.

## Fixes

- Project instructions reach every agent again, including work started from
  the Work composer.
- Under **Computers only**, a swarm task never falls back to this device.
- When a computer that stopped answering comes back, the changes a retried task
  left there are saved as a patch on the lost attempt, never applied over the
  retry. A computer that stopped answering stays skipped for ten minutes even if
  Jackalope restarts.
- Saving a TODO file on Windows no longer fails when another program briefly
  holds the file.
- Long titles and names fit on narrow windows in the task list, Cloud resources,
  swarm host settings and agent decisions.

## Known issues

- Autonomy, Cloud resources, swarms across computers and agents on a computer
  are in beta and have not yet been accepted on real computers. Computers use
  the new features after they update to the new image.
- Cloudflare sign-in may not accept every resource permission Jackalope asks
  for; if it refuses, the message lists the API token permissions to use
  instead.
- The phone companion is not in the App Store or Play Store yet. Installed
  phone builds pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop
  portal.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.17

Status: ready
Date: 2026-10-08

## Highlights

- A cleaner, more consistent workspace. Pages, tabs and controls now share one
  look, and views such as Agents, MCP connections and the Project tabs switch with
  a single segmented control whose selection slides between choices.
- Bots remember and keep their conversations together. Messaging a bot continues
  its latest open conversation, with a choice to start a new one, and bots save
  short notes they bring into later conversations. Review or remove those notes on
  the Bots page.
- Agents start sooner. Automatic tasks choose an agent while the workspace is
  still being prepared.

## Improvements

- Dialogs, menus and dropdowns ease in and out, and pages settle into place as
  they open. Reduced motion keeps everything still.
- The workspace sidebar is its own rounded panel, and the branch beside the
  project name is a clear, clickable chip.
- Project overview shows readiness as one list with a single fix for each item.
- Bot lists, template cards and agent options keep even sizes and alignment.
- Bots can search and reread their earlier conversations before guessing about
  past work, and edits to a bot's name and instructions reach its open
  conversations.
- The Bots item in the sidebar marks replies you have not read.
- Bots running on Grok Build, Antigravity and Gemini CLI can message other bots,
  show cards and keep notes too.
- Agents receive a shorter set of instructions focused on your workspace,
  permissions and review; Claude Code and Codex receive them as system
  instructions so the first message stays about your task.

## Fixes

- Long model lists scroll inside the agent picker instead of being cut off.
- Long-running tasks show elapsed time in hours and days instead of thousands of
  minutes.
- Status badges keep their contrast in dark themes.
- Updated bundled dependencies past newly reported high-severity advisories.

## Known issues

- Codex CLIs too old for your selected model fail with the provider's "requires a
  newer version of Codex" message. Update Codex, or choose another agent.
- Bot memory, wake-ups and messages between bots still need validation with real
  accounts in installed builds.
- Signed installation and updates still need validation on each platform.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

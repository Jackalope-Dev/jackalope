# Jackalope 0.1.11

Status: ready
Date: 2026-09-29

## Highlights

- Compare agents: send one request to up to four agents at once, see status,
  time, checks, changed lines and tokens side by side, and keep the best result.
- Tabs keep recently opened tasks and chats close at hand. Switch with Ctrl+1
  to 9 or Ctrl+Tab.
- Attach screenshots and files to requests by pasting, dropping or picking them.
- Each project keeps its own enabled agents, default agent and account choices.
- The `jackalope` terminal command works the way other agent CLIs do:
  `--resume`, `/model`, `/usage` and `/init`, with a clearer look.
- After each update, Jackalope shows what changed.

## Improvements

- Commit and push from Changes, with a clear confirmation and Push button.
- Work rows show how long an agent has been running, how many lines changed and
  a dot for results you have not opened yet.
- Changes shows recent commits across your local branches.
- Command search finds project files to open in your editor or attach to work.
- Press ? to see keyboard shortcuts.
- Usage & quota shows allowances and Ask Jackalope history more clearly, and
  routing respects account limits more reliably.
- Setup covers more agents, and macOS permission setup links straight to
  System Settings.
- The macOS installer opens to a branded drag-to-Applications window.
- Jackalope starts faster, and layout, spacing and colors are more consistent.
- Updated dependencies, including a security fix.

## Fixes

- Committing from Changes works when a deleted or renamed file was already
  staged in Git.
- Opening a task that belongs to a chat returns to that chat.
- Status colors stay readable in light mode, and app-wide errors show details
  and a reload action instead of a blank window.
- Project root worktrees are matched by path, so the right checkout opens.

## Known issues

- Signed installation and updates still need validation on each platform.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

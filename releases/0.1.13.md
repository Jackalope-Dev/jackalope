# Jackalope 0.1.13

Status: ready
Date: 2026-10-01

## Highlights

- Bots have their own home with guided setup, more ready-made templates and a
  simple conversation mode. Give each bot its own character style and colour.
- Parallel agents coordinate on their own: they adopt each other's finished
  work, hear about conflicts as they happen and split off subtasks.
- Quick questions skip workspace setup, and attempts that change nothing skip
  checks, so answers arrive sooner.
- Connect apps once for every agent, and watch what an agent's browser shows.
- Keep projects on Cloudflare Artifacts with your own Cloudflare account (beta).

## Improvements

- Agents show their familiar product icons in pickers, the Agents page, and
  capacity and usage views.
- Conversations read as a two-sided chat, and agent answers wrapped in code
  fences or indentation are shown as formatted text.
- Settings and project settings are rebuilt as clear cards, with tighter,
  more consistent spacing across the app.
- The branch indicator can switch to other live checkouts.
- Store members can request beta access from the app, and development and
  beta builds are labelled in the title bar.
- Jackalope checks for updates every hour instead of every six hours.

## Fixes

- Setup works when Git is not installed yet.
- Account data saves correctly on a fresh profile.
- Launch at login works in the Microsoft Store version.
- Message limits count characters, so non-English text is no longer cut short.
- Focus rings stay visible inside scrolling areas, and filled buttons stay
  readable with every accent theme.

## Known issues

- Signed installation and updates still need validation on each platform.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

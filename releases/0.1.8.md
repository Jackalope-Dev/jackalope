# Jackalope 0.1.8

Status: ready
Date: 2026-09-27

## Highlights

- The `jackalope` terminal command works the way other agent CLIs do:
  `--resume` picks or rejoins a conversation, `/model` chooses a model,
  `/usage` shows account quota and reset times, and `/init` writes `AGENTS.md`.
- A clearer terminal look: rounded menus with a highlighted row, readable
  secondary text, labelled agent replies and a working indicator.

## Improvements

- `/learn` saves what a terminal session taught into project context, and a
  rotating tip line highlights commands and shortcuts.
- `/clear` starts a fresh conversation, `/pause` and `/unpause` hold and send
  queued messages, and mistyped commands suggest the closest match.
- Task activity names the program each command runs, without its arguments.
- Agent descriptions in setup and the Agents page are short and plain.
- The Agents page has one Check again action and consistent header buttons.
- Setup can show or hide the theme picker in the top bar.
- Usage & quota shows allowances more clearly, and routing respects account
  limits more reliably.
- The commit file list sits below the message composer.
- Faster screens while typing: views update only when their data changes.

## Fixes

- Project root worktrees are matched by path, so the right checkout opens.
- Status colors stay readable in light mode, and some dialogs no longer lose
  their icon, border or background colors.
- Setup steps start at the top, and copy actions report when copying fails.
- Connections for a task's next step load again.
- "Needs you" counts read correctly for more than one item.

## Known issues

- This is a prerelease for testing. Signed installation and updates still need
  validation on each platform.
- `/usage` in the terminal needs this version of the app running as the host.
- Running tasks requires approved Jackalope account access and an installed,
  signed-in agent CLI or a connected API provider.

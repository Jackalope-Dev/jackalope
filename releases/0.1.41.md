# Jackalope 0.1.41

Status: ready
Date: 2026-11-26

## Highlights

- Edit from an earlier turn: rewind a Claude Code or Codex conversation to any earlier
  turn and send it differently.
- Jackalope no longer needs an account to run your agents. Account features such as
  Skill Sync ask for one where they appear.
- Build iOS apps with your agents: iOS projects on a Mac get a Simulator per task,
  agent tools that see and drive the app, a live preview and review screenshots.
- Bring your Claude Code and Codex history: import past conversations, grouped by
  project, and continue them where they ran.
- A new Overview page shows live work, each project's status and accounts near their
  limits.
- Devices brings phones, other computers and cloud machines together, starting from a
  map of this computer and what it's paired with.

## Improvements

- Work with GitLab merge requests and Bitbucket Cloud pull requests: open, follow and
  merge them, and import their issues.
- Setup lists the repositories you already work in, so you can add them in one step.
- Every keyboard shortcut can be rebound, and composers have slash commands, file
  mentions, a per-message effort choice and side questions.
- Long conversations with thousands of messages open and stream instantly.
- Codex keeps one session per conversation, so its turns start faster and can be
  interrupted.
- When an agent hits a usage limit, Jackalope shows when it resets and can resume the
  work then.
- New task worktrees can copy your local files, run setup commands and clean themselves
  up later.
- Finished tasks have a Report tab showing where the agent's time went.
- A ready merge can land as a short series of ordered commits.
- Turn a project lesson into a rule that warns about or blocks matching commands and
  file changes while an agent works.
- An optional turn advisor has another agent review each finished task turn.
- Agents controlling a window on Windows and macOS work in it behind your other
  windows, without taking your pointer or keyboard.
- A window you attach to a conversation starts at once and stays attached for the whole
  conversation until you detach it.
- Library can move screenshots and files Jackalope saved to the Trash, one at a time or
  in bulk. Files a task changed in your repository stay.
- Read aloud picks the most natural voice installed on your computer, and Settings lets
  you choose one and hear a sample.
- Agents on a computer can reach Anthropic and OpenAI through Jackalope, so your saved
  API key stays on this device.
- Automatic approval reads what Kimi and other ACP agents are about to run, so risky
  requests ask you first.
- Short, fully specified tasks skip the agent's opening restatement and finish sooner.
- Activity looks livelier: composers glow briefly when work starts, agent waits show
  thinking orbs, sending new work flows into its conversation and characters move
  more. Reduced motion keeps all of it still.
- Settings → Privacy lists exactly what usage and error counts are shared and shows
  this session's reports as they are sent.

## Fixes

- Skill Sync counts only the computers that sync, and connections are named after the
  computer rather than its network name.
- Read aloud stops when you press Stop.
- Back no longer stops recording pages after a step that lands somewhere slightly
  different.
- Plan with me works from an empty composer by switching it to plan mode.
- Settings cards no longer leave gaps beside shorter cards.
- Composers no longer draw a second focus ring inside their box, and the pop-out
  window's composer keeps its buttons at their own size.
- Feedback reports, phone companion responses, Jev requests and exported plans mask API
  keys, tokens and passwords.
- A finished conversation with an unsent message no longer shows as running.

## Known issues

- Edit from here, history import, the Overview page, GitLab and Bitbucket delivery, iOS
  building, Devices, Library's Trash, attached windows that last a conversation and the
  new activity effects have not yet been accepted in an installed app.
- Background desktop control works on Windows and macOS. On Linux X11, any input still
  pauses it, and grants there still start paused until Resume.
- Copy-on-write reuse of `node_modules` does not apply on Windows, which installs in
  full.
- Synced skill text is not end-to-end encrypted.
- The phone companion is not in the App Store or Play Store yet. Installed phone builds
  pair only over HTTPS, such as a Tailscale address.
- Desktop control on Wayland needs a desktop that offers the remote desktop portal.
- Signed installation and updates still need validation on each platform.

# Jackalope 0.1.0

Status: draft
Date: 2026-09-06

## Development preview

Jackalope is a desktop workspace for installed coding agents. This draft describes
the development version; signed installers and platform acceptance remain pending.

- Organize projects and tasks, run parallel queues in Git worktrees, and review
  changes before integration.
- Connect provider accounts, MCP tools and task-owned browser sessions.
- Keep project guidance, task history and reported usage in one workspace.

## Release limitations

- Native task execution requires approved Jackalope account access, including in
  source builds, and an installed, signed-in agent CLI.
- Signing, clean installation and upgrade checks must pass for each supported
  platform before publication.
- Remote execution and team collaboration are not available.

See the [current status](../docs/STATUS.md) for capabilities and limitations, and
the [release guide](../docs/RELEASE.md) for publication requirements.

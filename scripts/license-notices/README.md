# Supplementary dependency notices

These files supply upstream license texts omitted from a published package.
`pnpm licenses:generate` includes them in the relevant bundled notices.

| Package | Version | License source |
| --- | --- | --- |
| react-remove-scroll-bar | 2.3.8 | [Maintainer's upstream LICENSE](https://github.com/theKashey/react-remove-scroll-bar/blob/8ca9ba5ea52de03308fe8ced94f7b159a44d28ff/LICENSE) |

The upstream text is preserved unchanged. Review the source and update or retire
the corresponding generator entry when upgrading the package.

The published package declares MIT but omits the license text. Its npm `gitHead`
does not resolve in the public upstream repository; the linked revision records
the maintainer's explicit addition of the MIT license file.
